# 鸿蒙端验收记录

实现对照为本仓库 `apps/miniprogram` 的 WXML、WXSS、页面脚本和组件脚本。运行验证使用 Mate 90 Pro 模拟器，系统为 HarmonyOS 7.0.0 / API 26.0.0。

## 模拟器验收

| 项目 | 实际验证和范围 |
|---|---|
| 开发与构建 | DevEco CLI Debug、干净目录 Release 构建，Debug HAP 通过模拟器安装和启动。 |
| 今日 | 页面、底部导航、日期、进度、七日热力、开始训练和回顾入口可用。 |
| 训练 | 四个预设方案、默认标记、动作要领展开和播放器已实现。模拟器已完成一次 40 秒方案，完成回执显示 8 次。切系统桌面再回到应用，训练显示「已暂停」和「继续训练」。提前结束累计了完整动作的训练，只写入一条部分记录。 |
| 记录 | 已验证月历、上下月切换、重新选择日期、无记录提示、提前结束的部分记录和完成记录详情。同日目标后来修改时，历史仍显示记账时的目标快照。 |
| 设置 | 已验证修改每日目标并重开保留、切换深色、清空确认和清空后恢复默认。 |
| 数据 | 已验证开启模拟器飞行模式并强停后冷启动，部分记录与完整记录均可读取。导出操作可复制 JSON 文本，也可将带日期的 JSON 文件交给系统分享面板。 |
| 分享 | 已验证回顾卡、今日卡和首次达标里程碑卡预览、相册授权和成功提示，以及打开 PNG 系统分享面板。 |
| 小程序与共享包 | `pnpm check:miniprogram` 通过。共享包 Core 13 项、Data 5 项测试通过。 |

## 一比一对照范围

- 小程序实际页面有今日、训练、记录和设置四个标签。训练列表提供四个预设方案、动作要领和播放器。小程序数据操作为导出与清空。
- 已把小程序现有首页、训练和记录预览与鸿蒙截图并排查看。对照覆盖内容顺序、布局、颜色、卡片、日历、字号和素材。现有预览的日期、视口及微信宿主区域与模拟器不同。
- 待完成同日期、同数据、同逻辑视口下的完整截图与录屏对照。需要补齐两端设置页、深色、全部弹窗、暂停和恢复、完成回执，以及今日、回顾、里程碑三种分享卡。
- 鸿蒙「转发给朋友」调用系统分享面板。接收方获得卡片 PNG。小程序侧在微信内发送可以跳转小程序的转发卡片，此项需要确认可接受的鸿蒙交付形式。
- 鸿蒙相册授权、清空确认和备份选单使用系统控件。卡片落款使用「鸿蒙应用 · 提了么」。实际的微信接收、音效、触感、断网冷启动、锁屏和不同屏幕尺寸需要真机复验。
